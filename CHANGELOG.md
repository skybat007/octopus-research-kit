# Changelog

This project uses a lightweight public-release changelog for important changes to templates, scripts, research artifacts, and release preparation.

## 0.1.0 - 2026-05-28

- Established the core workspace structure, templates, roles, and quality gates for open-source technology research.
- Added the `open-source-tech-research` skill to guide agent-based source research and evidence-backed outputs.
- Added generation scripts for dashboards, Markdown readers, visual architecture diagrams, and evidence viewers.
- Added research directories for OpenClaw, Hermes Agent, A2UI, and example-framework.
- Added release-safety checks, research validation, privacy checks, and GitHub Actions validation.
