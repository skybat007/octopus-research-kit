# Glossary

本文件用于维护项目中的业务和技术术语，避免 Code Agent 在生成需求、设计和代码时偷换概念。

| 术语 | 定义 | 相关系统 | 不应混淆的概念 | 示例 |
|---|---|---|---|---|
| 主智伴 | 面向用户入口和综合任务编排的智能体 | 主智伴 | 不等同于角色智伴 | 用户在主智伴发起能力安装 |
| 角色智伴 | 面向具体业务角色的智能体，通常承载角色相关技能和运行态任务 | OpenClaw / 角色系统 | 不等同于主智伴 | 客户代表角色智伴 |
| OC 管理服务 | 负责 OpenClaw 实例管理、Skill 安装、实例配置、状态查询等能力 | OC 管理服务 | 不得随意命名为 Skill 安装服务，除非项目中明确存在该服务 | 下发 Skill 安装请求 |
| 能力集市 | 提供可安装、可查询、可匹配能力或 Skill 的系统 | 能力集市 | 不等同于 OC 管理服务 | 查询可安装 Skill |
| OpenClaw 实例 | 用户或组织对应的 OpenClaw 运行实例 | OpenClaw | 不等同于 OC 管理服务 | 安装 Skill 的目标实例 |
