# Archived Legacy Specs

本目录用于存放从其他项目迁移来的旧业务 spec。它们不属于当前技术调研工作流，仅作为历史参考。

推荐结构：

```text
docs/specs-archive/
  legacy/
    <feature-name>/
      README.md
      requirements.md
      design.md
      tasks.md
```

## 使用规则

- 新的技术调研不要写入本目录。
- 新的技术调研统一写入 `docs/research/<framework-name>/`。
- legacy 内容中的旧路径、旧业务名和旧链接不再作为当前项目约定。
