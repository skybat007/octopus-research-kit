# 历史 Spec 归档

本目录用于存放从其他项目迁移来的旧业务 spec。它们不属于当前技术调研工作流，仅作为历史参考。

当前目录仅保留归档说明。若后续确实需要保留旧业务 spec，可以按来源或主题建立子目录：

```text
docs/specs-archive/
  <source-or-topic>/
    README.md
    requirements.md
    design.md
    tasks.md
```

## 使用规则

- 新的技术调研不要写入本目录。
- 新的技术调研统一写入 `research/<framework-name>/`。
- 归档内容中的旧路径、旧业务名和旧链接不再作为当前项目约定。
